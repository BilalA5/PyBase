# PyBase

PyBase is a Python-based **Inventory Management System** that provides a simple GUI and backend interface to manage stock records stored in a local **SQLite database**.  
It demonstrates core software engineering concepts such as **relational database design**, **CRUD operations**, and **GUI development** in Python.

---

## 🚀 Features
- **GUI Interface:** Built with **Tkinter** for intuitive record management.
- **Persistent Storage:** Uses **SQLite3** for a lightweight relational database.
- **CRUD Operations:** Add, update, delete, and search inventory items.
- **Stock Tracking:** Automatically adjusts stock levels for simulated sales and restocking.
- **Modular Codebase:** Separates GUI, operations, and database logic for clarity and maintainability.
- **Efficient Performance:** Handles typical record queries in **sub-0.05 s** on a demo-scale dataset.
